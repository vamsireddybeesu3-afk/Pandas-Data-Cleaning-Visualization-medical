
# Medical Appointment No-Show Analysis

## Project Overview
This project analyzes medical appointment data to understand patient attendance and missed appointments (No-Shows).

The project uses Python libraries to clean, manipulate, analyze, and visualize the dataset.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks
- Imported and explored the medical appointment dataset.
- Cleaned and manipulated data using Pandas.
- Analyzed appointment attendance and no-show records.
- Explored SMS reminder information.
- Created charts and visualizations using Matplotlib and Seaborn.

## Key Objectives
- Understand patient appointment attendance.
- Explore factors associated with missed appointments.
- Analyze SMS reminder information.
- Present findings through data visualizations.
